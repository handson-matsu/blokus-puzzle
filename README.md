# ブロックス・パズル

HTML / CSS / JavaScriptだけで動く、1人用ポリオミノ配置パズルです。外部通信、CDN、外部フォント、ビルド、サーバーAPIは使用しません。親フォルダーの「マイ敷き詰めメーカー」とは独立しています。

## 起動と公開

このフォルダーの `index.html` をブラウザで開くと遊べます。必要なファイルは `index.html`、`style.css`、`engine.js`、`puzzles.js`、`solutions.js`、`app.js` の6つです。同じフォルダーに置いてください。

このリポジトリをGitHub Pagesで公開した場合は `/blokus-puzzle/` から利用できます。別のリポジトリとして公開する場合は、このフォルダーの中身を公開ルートにコピーしてください。公開操作はまだ行っていません。

## 操作

1. 未使用ピースを選びます。
2. 左回転・右回転（90°）、左右反転で向きを変えます。
3. ピース図の ● のマスを置きたい位置で盤面をタップします。緑の点は現在の向きで配置可能な位置です。PCではカーソル位置に配置予告を表示します。
4. 最初のピースは ★ を含み、その後は配置済みピースと角で接する必要があります。異なるピース間の辺接触・重複・盤外配置は禁止です。ピース内の辺接触は問題ありません。
5. 指定ピースをすべて置くとクリアです。空きマスが残って構いません。

配置済みピースをタップして「選択した配置を取り消す」を押すと、そのピースが一覧に戻ります。取り消し後にスタートから角でたどれなくなったピースも戻します。別の経路でつながっているピースは残します。「1手戻す」は配置と取り消しを1操作ずつ戻します。回転・反転は未配置ピースの向きの操作なので履歴には含めません。

「最初から」と問題切り替えはその問題の配置・履歴をリセットします。編集内容の永続保存はありません。

## 問題を追加する

`puzzles.js` の配列に追加するだけで、問題メニューと「次の問題」に反映されます。50〜100問への追加でもゲーム本体の変更は不要です。

```js
{number:26, title:'新しい問題', difficulty:3, width:8, height:8,
 start:[0,0], pieces:['F5','I5','L5','1']}
```

- `number`: 表示する問題番号（重複させない）
- `difficulty`: 1〜5。画面の星表示に使用します。
- `width` / `height`: 列数 / 行数。正方形の盤面には同じ数を指定します。
- `start`: `[列, 行]`、左上が `[0,0]`。盤内を指定します。
- `pieces`: 使用するピースID。1問では各種類1枚、IDは重複させないでください。

全21種類のID：`1`, `2`, `I3`, `L3`, `I4`, `O4`, `T4`, `L4`, `S4`, `F5`, `I5`, `L5`, `P5`, `N5`, `T5`, `U5`, `V5`, `W5`, `X5`, `Y5`, `Z5`。

形状と純粋な配置判定は `engine.js`、画面と操作は `app.js` に分離しています。新規問題は `tools/solver.cjs` の `solve(problem)` で解を確認してから採用してください。上限到達による未確定と、全探索による解なしを区別します。

## 検証

- `node tests/rules.cjs`: 独立したポリオミノ列挙との比較による全21種類の確認、回転・反転、盤外・重複・辺・角接触、取り消し後の接続、全25問の解手順の再検証。
- `node tests/browser.cjs`: PlaywrightとChromeが必要です（アプリ利用には不要）。タップ配置、不正配置防止、取り消し・1手戻す・リセット、回転・反転、全25問のクリア・星表示と次の問題、最終問題、画面の横はみ出しと外部通信がないこと。

ChromeのモバイルエミュレーションとPC幅で確認済みです。スマートフォン実機では未検証です。

## 難易度とソルバー

問題1〜5は従来の練習問題（★）をそのまま保持しています。6〜10が初級（★★）、11〜15が中級（★★★）、16〜20が上級（★★★★）、21〜25が難問（★★★★★）です。

1,000候補の解探索から20問を採用しました。解の少なさ、解につながる初手の割合、2,000回の無作為な合法手プレイの成功率、形状・開始位置の違いを合わせて選定しています。難易度は人間によるプレイテストで校正したものではなく、これらの指標からの推定です。

- `tools/solver.cjs`：ピースの配置順に依存しない解探索・対称性を除いた解数計算・無作為プレイ評価。例：`node tools/solver.cjs 25`。
- `tools/generate.cjs`：固定seedで問題候補を生成・評価。`node tools/generate.cjs 1000`。
- `tools/curate.cjs`：レビュー済み候補を再探索し、問題データと解析レポートを出力。`node tools/curate.cjs`。
- `analysis/REPORT.md`：全問の解数・ノード数・初手数・無作為成功率と選定理由。
- `analysis/verified.json`：全問の検証結果と解手順（ネタバレを含みます）。
- `analysis/candidates.csv` / `candidates.jsonl`：1,000候補の評価記録。
- `tests/solver.cjs`：独立した全配置順探索との解数比較、ゲームの判定との照合。
- `tests/catalog.cjs`：25問の解数と探索ノードを再計算し、一意性・練習問題の保持を確認。

問題6〜25の解数は全探索済みの確定値です。問題15・18・25は、スタートを保つ盤面の対称性と配置順序を除いて一意解です。練習3〜5は10,000解で打ち切った下限値を保存し、`solutionCountExact: false` で区別しています。

解数・探索量などはプレイヤーに表示しません。ソルバー・解析ファイル・テストは開発用であり、ブラウザでのゲーム動作に追加のライブラリや通信は必要ありません。配布用には検証済み解答の `solutions.js` も含めてください。

## 開発者・管理者用の解答確認

タイトル「ブロックス・パズル」を2秒以内に5回タップ／クリックすると管理者モードを切り替えます。通常画面には管理者ボタンや操作案内を表示しません。ONの間だけ小さな「解答を表示」ボタンが現れます。再読み込みでOFFになります。

「解答を表示」で現在の問題の正解例を閲覧できます。閲覧中は問題変更・配置操作を無効化し、クリア扱いにはしません。「解答を閉じる」またはタイトル5回でOFFにすると、元の配置・選択・向き・履歴・メッセージに戻ります。このモードは開発用の隠し操作であり、認証機能ではありません。

`solutions.js` は `analysis/verified.json` のソルバー検証済み解手順を収録します。問題を更新・追加して解析結果を再生成したら `node tools/export-solutions.cjs` で解答も更新してください。ブラウザ内の探索や外部通信は不要です。

- `node tests/solutions.cjs`：全25問の解答と解析結果の一致、指定ピース・形状・配置順の合法性を現在のゲームルールで検証。
- `node tests/admin-browser.cjs`：PlaywrightとChromeでスマートフォン相当のタップ・PCクリック、5回判定と時間切れ、ON/OFF、再読み込み、全25問の盤面表示、状態復元と閲覧中の操作制限を検証。
